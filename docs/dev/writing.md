# 用语规范

> 适用范围: 注释、docstring、`docs/dev/`、提交说明、Pull Request 标题与正文、与维护者的对话、新撰写的用户可见中文文案.
> 不适用: 源码标识符、协议字段名、既有 i18n key、日志 event 名. 不批量改写既有文案.
>
> 与其它 Agent 引导条款冲突时, 以本文为准.

## 语体

使用书面技术文档用语. 句子完整, 操作对象与结果明确. 禁止口语、语气词、以及省略到产生歧义的短句.

| 禁止 | 使用 |
| ---- | ---- |
| 搞、弄、搞定、弄成 | 写所执行的操作: 修改、实现、删除 |
| 那个、这种东西、后面没法 | 具体名称与可验证的后果 |
| 那些还要 | 上述路径、该文件、命中项 |

## 动词

谓语动词须为双音节或以上. 禁止单音节动作动词独立作谓语. 判断与存在 (是、有、无、在) 不在此列.

| 禁止 | 使用 |
| ---- | ---- |
| 扫 | 扫描、遍历 |
| 撞 | 违反、冲突、占用 |
| 进 | 进入、写入、移动至 |
| 丢、丢掉 | 排除、删除、丢弃 |
| 改 | 修改、更改 |
| 清 | 删除、清除 |
| 看 | 检查、依据 |
| 走 | 执行、采用 |
| 跑 | 运行、执行 |
| 拿 | 读取、取得 |
| 放 | 放置、写入 |
| 收 | 收集、归档 |

「扫描」「遍历」为双音节, 可以使用.

## 禁止比喻

禁止借用其他学科、日常场景或其它软件产品的说法代替对本系统机制的直接描述. 写对象、条件与后果.

本仓库已固定的领域词可以继续使用: 刮削、落盘、归档、`.amane_trash`、路径模板、UNIQUE 约束. 禁止在此之外新造比喻.

| 禁止 | 使用 |
| ---- | ---- |
| 幽灵行 | 磁盘上已不存在、仍保留在库中的 MediaFile 记录 |
| 收口 | 未纳入索引或不匹配 glob 的文件仍执行归档 |
| 占住 | 占用 (约束 / 路径) |
| 内存分流 | 一次遍历的结果在内存中分类后分别归档与落盘 |
