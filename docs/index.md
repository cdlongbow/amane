# Amane

AI 时代的私人影库. 监控媒体目录, 多源刮削, 与 Emby / Jellyfin 集成, 作为流媒体服务的元数据补充.

- **自动监控** — 磁盘文件变化后自动刮削
- **本地优先** — 持久化已获取数据, 重复刮削走缓存
- **多源择优** — 按字段聚合多个数据源
- **目录管理** — 自定义命名规则, 目录结构可改
- **图片增强** — 超分低清海报
- **AI 助理** — 自然语言检索、批量整理、发起刮削
- **Web 界面** — 海报墙、任务队列、结构化日志、可视化设置

安装与日常使用见 [用户指南](user/index.md). 源码与发行版: [GitHub](https://github.com/sqzw-x/amane).
